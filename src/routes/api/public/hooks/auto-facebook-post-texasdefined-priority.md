# TexasDefined Facebook article priority

The TexasDefined Facebook publisher now selects from the live TexasDefined sitemap and intentionally favors traffic-driving gateway/list content instead of simply choosing the newest eligible page.

Selection signals include numbered/list-style slugs and titles plus terms such as `things`, `best`, `before`, `reasons`, `facts`, `road-trip`, `guide`, `places`, `visit`, `camping`, `state fair`, `bluebonnet`, and related Texas travel/list intent.

Safeguards remain in place:

- Maximum 2 TexasDefined Facebook posts per Central-time day.
- Minimum 180 minutes between posts.
- Live Facebook duplicate verification before publishing.
- 45-day URL cooldown using publishing history.
- Only sitemap-eligible TexasDefined article/news/featured routes with valid Facebook-ready images may publish.
